# HSK 듣기 탭 설계서

- 작성: 2026-10-09
- 대상 회차: HSK 3급 공식 모의고사 H31001~H31005 (회차는 계속 추가할 수 있게)

## 목적

공식 모의고사 음원은 약 36분인데, 안내 멘트·유형 설명·예시·답 고르는 시간·두 번째 낭독이 섞여 있어 듣기 공부용으로 쓰기 불편하다. 문제 낭독만 남긴 음원과 문항별 대본·해설을 앱의 «듣기» 탭에 넣어, 문제를 많이 듣고 바로 확인하는 공부를 하게 한다.

## 성공 기준

- 회차·부분을 고르면 문항 하나씩 «듣기 → 답 고르기(또는 모르겠음) → 대본·해설 확인»을 할 수 있다.
- 문항 음성에는 그 문항의 첫 번째 낭독만 들어 있다. 안내·예시·두 번째 낭독·긴 공백이 없다.
- 고른 부분을 문항 사이 2초 쉼으로 끝까지 이어 들을 수 있다 (화면을 꺼도 계속).
- 대본은 한자 아래 병음이 주가 되고, 한글 해석·핵심 단어·문장 구조 설명이 붙는다.
- 듣기 핵심 단어가 기존 단어장·랜덤 학습에 «HSK3 듣기» 단원으로 들어간다.

## 화면 (듣기 탭)

- 탭 줄에 «듣기»를 추가한다.
- 회차 칩(H31001…), 부분 칩(전체/1~4부분), «이어 듣기» 버튼.
- 문항 카드: 번호·부분·유형 안내, ▶ 문제 듣기(멈춤을 누를 때까지 약 1.5초 쉼을 두고 되풀이, 몇 회째인지 표시) / ■ 멈춤, 보기.
  - 1부분: PDF에서 잘라낸 사진 묶음 + A~F(또는 A~E) 버튼
  - 2부분: ★ 문장 + ✓ / ✗ 버튼
  - 3·4부분: A·B·C 보기 글 (병음은 공개 후)
  - 모든 부분에 «모르겠음» 버튼. 3·4부분에서는 «D 모르겠음».
- 보기를 고르면 정답·오답을 표시하고 아래를 펼친다: 대본(한자 아래 병음), 한글 해석, 핵심 단어, 문장 구조. «대본 보기»로 고르지 않고도 펼칠 수 있다.
- 풀이 기록은 localStorage `sungmi-vocab-listening-v1`에 `{ "H31001": { "23": "A", "24": "?" } }`로 저장한다 (`"?"`=모르겠음). 회차별 «맞힘·틀림·모름»을 보여준다. 오답 다시 풀기는 이번 범위가 아니다.
- 이어 듣기: 고른 부분의 첫 문항 시작부터 마지막 문항 끝까지 한 파일을 재생한다. 재생 중인 문항 번호를 카드에 따라 보여준다.

## 데이터·파일

```
public/listening/H31001.mp3        문제 낭독만 이어 붙인 음원 (모노 32kbps CBR)
public/listening/H31001.json       문항 데이터 (회차를 고를 때 fetch)
public/listening/H31001-p1-1.jpg   1부분 사진 묶음 (1-5번, 6-10번)
src/data/listening-index.json      회차 목록 (앱에 묶임)
src/Listening.jsx                  탭 화면
src/listeningTools.js              구간 재생·풀이 기록 도우미
tools/listening/                   처리 스크립트 (배포 안 됨)
```

문항 데이터:

```json
{ "no": 23, "part": 3, "start": 312.4, "end": 321.9,
  "choices": { "type": "text", "options": [{ "label": "A", "words": [["去","qù"],["医院","yīyuàn"]], "ko": "병원에 간다" }] },
  "answer": "A",
  "script": [{ "speaker": "男", "words": [["你","nǐ"],["怎么","zěnme"]], "ko": "너 왜…" }],
  "vocab": [{ "hanzi": "还", "pinyin": "hái", "meaningKo": "아직", "partOfSpeech": "부사" }],
  "grammar": [{ "pattern": "还没 + 동사", "note": "'아직 ~하지 않았다'…" }] }
```

- `choices.type`: `picture`(1부분, `image`·`labels`), `truefalse`(2부분, `statement`), `text`(3·4부분, `options`).
- «모르겠음»은 데이터에 없고 화면에서 붙인다.
- `start`/`end`는 이어 붙인 mp3 기준 초.

## 처리 과정 (tools/listening)

중간 파일과 Whisper 모델은 Google Drive 밖 `~/hsk-listening-work/`에 둔다.

1. **paper**: PDF 텍스트에서 听力材料(문항별 대본), 答案(정답), 시험지의 2부분 ★ 문장·3·4부분 보기를 뽑는다. 1부분 사진 묶음은 글자 좌표(`pdftotext -bbox`)로 영역을 찾아 png로 자른다.
2. **align**: ffmpeg `silencedetect`로 무음 구간을, whisper.cpp(small, zh)로 받아쓰기·시각을 얻는다. 받아쓴 글과 대본을 **성조 없는 병음**으로 바꿔 비교한다(번체·동음 오인식에 강함). 각 문항의 첫 번째 낭독 구간을 찾고 경계를 가까운 무음으로 옮긴다.
3. **audio**: 첫 낭독만 잘라 2초 쉼을 넣고 이어 붙여 mp3로 만들고, 새 파일 기준 구간을 기록한다.
4. **verify**: 잘린 조각마다 다시 받아써 대본과의 병음 일치도를 매긴다. 낮은 문항은 목록으로 뽑아 사람이 듣는다. 문항 40·정답 40·조각 길이 3~40초도 확인한다.
5. **enrich**: 단어 분절·병음·한글 해석·핵심 단어·문장 구조를 회차별로 만든다(Claude). 병음은 기존 단어장 관례대로 不·一 변조를 표기하고(`bú shì`, `yí ge`) 경성은 성조 없이 쓴다.
6. **check-enrich**: 단어 묶음의 한자를 이으면 원문과 정확히 같아야 한다. `pypinyin`과 대조해 다른 글자를 뽑아 다음자·변조 외의 오류를 고친다.
7. **assemble**: paper·구간·해설을 합쳐 `public/listening/<회차>.json`을 쓰고, 핵심 단어 중 단어장에 없는 것을 `vocab.json`에 «HSK3 듣기» 단원으로 추가한다(예문=그 단어가 나온 대본 문장).

## 해설 기준

- 원문 한자는 PDF 그대로 둔다. 추정해서 바꾸지 않는다.
- 핵심 단어: 문항당 3~6개, HSK 3급 수준 위주(HSK1 기초어는 뺀다).
- 문장 구조: 문항당 1~3개, 접속사·구문 패턴 위주(除了…还…, 越…越…, 把자문, 比 비교문, 결과보어 등).

## 범위 밖

오답만 다시 풀기, 재생 속도 조절, 독해 파트.
